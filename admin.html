Hubungkan Supabase Cloud Database

Menghubungkan database cloud agar data akun CoC tersimpan secara online dan dapat diakses pembeli dari seluruh dunia secara realtime.

📌 Panduan Cepat Supabase (3 Menit Selesai):
  1. Buat project gratis di supabase.com.
  2. Buka menu SQL Editor di dashboard Supabase Anda.
  3. Salin dan jalankan seluruh isi file schema.sql yang ada di folder proyek ini.
  4. Buka Project Settings → API, lalu salin Project URL dan anon/public key ke form di bawah ini.
